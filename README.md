# CrewPulse starter kit

Unzip into the root of your Next.js repo (see TEAM_PLAN.md section 2 for the scaffold commands).

- PRD.md: what to build (read first)
- TEAM_PLAN.md: who does what, timeline, git workflow, prompts
- CLAUDE.md / AGENTS.md / .cursor / .github: AI rules (identical)
- supabase/schema.sql: run in Supabase SQL editor
- src/lib/types.ts: shared contract
- .claude/commands: /feature and /verify
- .mcp.json.example, .env.example, .gitignore.append
